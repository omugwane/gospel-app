# Tailwind Color Configuration

## Color Choices

- **Primary:** `violet` — Used for buttons, links, key accents. Use `primary-*` semantic classes.
- **Secondary:** `amber` — Used for tags, highlights, secondary elements. Use `secondary-*` semantic classes.
- **Neutral:** `stone` — Used for backgrounds, text, borders. Use `neutral-*` semantic classes.
- **Urgency:** `red` — Live indicators, urgent prayer buttons, alert states. Use `urgency-*` semantic classes.

## Usage Examples

Primary button: `bg-primary-600 hover:bg-primary-700 text-white`
Secondary badge: `bg-secondary-100 text-secondary-800`
Neutral text: `text-neutral-600 dark:text-neutral-400`
Urgency/live: `bg-urgency-500` (live dot), `bg-urgency-600` (CTA button)
